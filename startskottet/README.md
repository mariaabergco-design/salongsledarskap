# Startskottet som ledare

Försäljningssida för instegserbjudandet Startskottet (14 900 kr + moms):
Salongsledarskap och Personalmöteskursen digitalt, fem gruppcoachingar,
uppstarts- och avslutningsmöte med Maria.

Mappen publiceras av ett eget Vercel-projekt, `startskottet`, med `startskottet`
som rotmapp. Byt datum i tabellen i `index.html` och kör sedan
`python3 scripts/bygg-startskottet-kalender.py`.
